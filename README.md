# ख़ामोशी की आवाज़

A simple ebook-style website and interactive flip book for the poetry collection by तेजिंदर कौर.

## Contents
- Ebook-style landing page
- Approved 10-page poetry flip book
- Responsive layout
- Contents navigation
- Fullscreen reader
- Keyboard and swipe page turning

Open `index.html` in a modern browser.
